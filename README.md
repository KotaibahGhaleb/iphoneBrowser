# Browser

متصفح iOS بسيط (SwiftUI + WKWebView) يفتح موقعاً محظوراً **بدون VPN وبدون أي تكلفة**.

في التطبيق ثلاثة أوضاع اتصال (من الإعدادات ⚙️):

| الوضع | التكلفة | الوصف |
|-------|---------|-------|
| **تلقائي** | مجاني | يجلب قائمة بروكسيات مجانية ويجربها واحداً واحداً حتى يجد واحداً يفتح الموقع |
| **مرآة (بدون بروكسي)** | مجاني | رابط `workers.dev` تنشئه بنفسك على Cloudflare — الأثبت والأسرع |
| **يدوي** | يحتاج سيرفر | بروكسي SOCKS5/HTTP خاص بك إن توفر لاحقاً |

الوضع التلقائي يعتمد على `WKWebsiteDataStore.proxyConfigurations` (يتطلب **iOS 17+**) —
البروكسي يخص متصفح التطبيق فقط ولا يؤثر على باقي الجهاز.

## حظر الإعلانات

التطبيق فيه مانع إعلانات مدمج (مفعّل افتراضياً، وفيه toggle بالإعدادات):

- **`Sources/blockerList.json`** — قائمة `WKContentRuleList` تحجب طلبات شبكات
  الإعلانات (exoclick, popads, trafficjunky, adsterra, taboola…) وتخفي الحاويات
  الإعلانية بالـ CSS.
- **منع النوافذ المنبثقة**: أي تنقّل أو `window.open` لدومين إعلاني معروف يُلغى
  قبل ما يفتح.
- القائمة تعمل في كل الأوضاع — حتى مع المرآة، لأن المطابقة على نص الرابط كاملاً.
- لو سبّب الحظر مشكلة في صفحة معيّنة، عطّله من الإعدادات.

---

## 1) بناء الـ IPA على GitHub

1. ارفع المشروع على مستودع GitHub.
2. من تبويب **Actions** شغّل **Build unsigned IPA** (أو ادفع commit على `main`).
3. حمّل artifact اسمه `Browser-unsigned` — بداخله `Browser-unsigned.ipa`.
4. وقّعه بخدمة التوقيع عندك وثبّته على الايفون.

## 2) الخيار الأول — الوضع التلقائي (صفر إعداد)

- الافتراضي في التطبيق — أول تشغيل يبحث تلقائياً.
- يجرب حتى 25 بروكسياً عاماً؛ إذا انتهت المحاولات اضغط **«إعادة البحث»** من الإعدادات.
- البروكسيات العامة تتفاوت بالسرعة وتموت بسرعة — إذا لقيت وحدة شغالة وبطيئة، أعد البحث.
- **لا يحتاج أي إعداد خارجي إطلاقاً.**

## 3) الخيار الثاني — مرآة Cloudflare (الأثبت، مجاني بدون بطاقة)

الفكرة: Worker مجاني ينسخ الموقع على رابط خاص فيك `xxx.workers.dev`، والتطبيق يفتحه كأنه
موقع عادي — لا بروكسي ولا سيرفر.

### خطوات النشر (من المتصفح، بدون أوامر):

1. سجّل حساباً مجانياً في [cloudflare.com](https://cloudflare.com) (لا يطلب بطاقة).
2. من القائمة الجانبية: **Workers & Pages** → **Create** → **Create Worker** → **Deploy**.
3. اضغط **Edit code**، احذف المحتوى، والصق كامل ملف [`worker/worker.js`](worker/worker.js).
4. اضغط **Deploy** → خذ رابطك من نوع `https://mirror.xxx.workers.dev`.
5. في التطبيق: الإعدادات → **الوضع: بدون بروكسي** → **الصفحة الرئيسية: رابطك**.

> بديل بالسطر: `npm i -g wrangler && wrangler login && cd worker && wrangler deploy`

السكربت يعيد كتابة روابط الصفحات والفيديو (manifests وملفات الميديا) لتمر كلها عبر المرآة —
بما فيها روابط CDN الخارجية عبر مسار `/u/`.

## 4) الخيار الثالث — بروكسي خاص (إن توفر سيرفر لاحقاً)

على أي VPS خارج البلد:

```bash
docker run -d --name proxy --restart always -p 1080:1080 ginuerzh/gost -L "socks5://USER:PASS@:1080"
```

ثم في التطبيق: **يدوي** → SOCKS5 → العنوان والمنفذ والبيانات.

## ملاحظات وحدود معروفة

- **iOS 17+** مطلوب للوضعين التلقائي واليدوي (وضع «بدون بروكسي»/المرآة يعمل على أي إصدار).
- البروكسيات العامة تكشف الدومين اللي تتصفحه فقط (المحتوى مشفّر بـ HTTPS) — لا تدخل
  حسابات أو بيانات حساسة أثناءها.
- المرآة: لو الموقع فعّل حماية بوتات قوية قد تتعطل بعض الطلبات — غالباً تشتغل، لكن لو
  ظهرت صفحة تحقق أخبرني.
- في حالات نادرة مشغّل الفيديو قد لا يمر عبر بروكسي الـ WebView — المرآة تحل هذا لأن
  الفيديو نفسه يأتي من نطاق المرآة.
- خطة Cloudflare المجانية: 100 ألف طلب/يوم — أكثر من كافية للاستخدام الشخصي.
