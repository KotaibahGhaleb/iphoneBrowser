# Browser

متصفح iOS خفيف ومخصص للتصفح الخاص (SwiftUI + WKWebView).

## الميزات

- **شريط عنوان + بحث** — اكتب رابطاً أو كلمة بحث (DuckDuckGo).
- **وضع التخفي** — كوكيز وجلسات وبيانات لا تُحفظ (مفعّل افتراضياً).
- **حظر الإعلانات** — قائمة `WKContentRuleList` تحجب شبكات الإعلانات والمتتبّعات
  + منع النوافذ المنبثقة والـ popunders + إخفاء الحاويات الإعلانية.
- **معاينة باللمس المطوّل** — ضغطة مطوّلة على الصورة تعمل كـ hover وتشغّل معاينة الفيديو.
- **صفحة رئيسية مدمجة** — `start.html` بشبكة 20 موقعاً (تشتغل بدون إنترنت).
- **قفل بالبصمة / الرمز** — قفل التطبيق عند الفتح وبعد الخلفية (اختياري).
- **حجب معاينة المهام** — شاشة سوداء تغطي المحتوى في مبدّل التطبيقات.
- **زر الذعر** (الممحاة) — يمسح الجلسة فوراً ويرجعك للصفحة الرئيسية.
- **ملء الشاشة** — المحتوى يمتد تحت النوتش، شريط أدوات سفلي شفاف.

## البناء

### Codemagic (موصى به — 500 دقيقة مجانية/شهر)

`codemagic.yaml` جاهز: اربط الريبو في codemagic.io → اختر workflow
**Build unsigned IPA** → Start new build → حمّل `Browser-unsigned.ipa` → وقّعه وثبّته.

### GitHub Actions

`.github/workflows/build-ipa.yml` يبني IPA غير موقّع على runner `macos-13`
(يعمل فقط إذا كانت لدى حسابك دقائق macOS متاحة — الريبو العام أسهل).

## الاستخدام

- زر 🏠 يرجع للصفحة الرئيسية (اكتب `start` في الإعدادات لصفحة المواقع، أو أي رابط).
- زر الممحاة = **ذعر**: يعيد إنشاء المتصفح بحالة نظيفة فوراً.
- الإعدادات ⚙️: قفل بالبصمة، تخفي، مسح بيانات التصفح، حظر الإعلانات، معاينة اللمس.

## ملاحظات

- يتطلب iOS 17+.
- مجلد `worker/` يحتوي سكربت Cloudflare Worker اختياري يعمل كمرآة للمواقع —
  غير مستخدم افتراضياً لكنه متاح لو احتجته.
- `Sources/blockerList.json` قائمة الحظر — أضف دومينات لها إذا طلّع إعلان جديد.
